Scope

Scoot(34) — The Dream Laboratory is a RIM design: work executed on a RIM machine. A design is not merely produced by the pattern — it occupies positions 1 and 2 of the chain one turn down, which is why a design is literally a RIM instance rather than an analogy.

Its Map and its Model

Map — positional truth

The live Postgres: who exists, what each member may write, where a message lands, who the trustee is. Where the Scoot's parts actually are.

Model — the account

The personality prompt and the ordered command router — what the Scoot does — plus the architecture notes that predict it.

The invariant to hold yourself to: these two must be the same artifact. Today they are two: the database, and the code plus the prompt. The questionnaire of 2026-09-07 found six live disagreements between them, and all six were closed on 2026-09-08 — a stale test-status table, a daemon documented as owning a ledger it has never run, a development environment that had moved to production, a flags table missing three flags, a folder map that no longer matched the tree, and a roster count. None are known open today. Closing them one by one is not the same as the two artifacts becoming one, though, which is the gap the pattern says costs you, and naming it is more useful than hiding it.
