dreamlab

level 2 · a RIM machine
Scope

dreamlab is a RIM machine — an implementation of Recursive Integration, not a design produced by one. It is the substrate its designs execute on: the assistant, its services, and the shared artifacts that let several agents work one tree without destroying each other's information at the hand-off.

What makes it a RIM machine

One shared artifact

An append-only event log is the sole truth; current state is a fold over it, never a cached snapshot.

Positional authority

The owner of a file is the session whose working directory contains it — never a session name. Names drift; directories don't.

Non-blocking hand-off

Contended resources have one writer. Others don't wait — they hand off a payload and keep authoring.

Recursive improvement

The machine is built to build its designs; improving a design's process immediately improves the machine.

Status, honestly: as of 2026-09-08 these four cards describe the target, not the state.
